# Silver Oak University Practicals & Materials (2026-28)

This repository contains practical assignments, theoretical notes, and other educational materials for MCA students at Silver Oak University. The content is organized systematically by academic year and semester.

## 📂 Repository Structure

### First Year (F.Y.)

#### Semester 1

- **Computer Network (CAM5021C)**:
  - Study materials and syllabus documents.
- **Core Java (CAM5001C)**:
  - `CollegePracticals/`: Java source code (`.java`) and compiled classes (`.class`) for laboratory assignments. Includes programs like Armstrong, Factorial, loops, and inheritance.
  - `Theory/`: Unit-wise presentations, lecture notes, syllabus PDF, and assignments.
- **DBMS (Database Management System)**:
  - `CollegePracticals/`: SQL schemas and database queries.
  - `Theory/`: Unit-wise lecture presentations.
- **Foundation of Mathematics**:
  - Unit-wise tutorials, lecture notes (Numerical Methods, Operations Research), assignments, and the MCA syllabus.

## 🚀 Getting Started

Navigate to the specific year and semester directory to find the relevant code, schemas, and notes.

For example, to access the Core Java practicals, you can navigate to:

```bash
cd F.Y./Sem-1/CoreJava/CollegePracticals/
```

To run a Java practical, simply compile and run using standard Java commands:

```bash
javac FileName.java
java FileName
```

# Silver Oak University Theory & Practicals

This repository contains practical assignments, theoretical notes, and other educational materials for students at Silver Oak University. The content is organized systematically by academic year and semester.

## 📂 Repository Structure

### First Year (F.Y.)

#### Semester 1
- **Computer Network**: Theoretical notes and materials.
- **Core Java**: 
  - `CollegePracticals/`: Java source code (`.java`) and compiled classes (`.class`) for laboratory assignments.
  - `Theory/`: Notes and theoretical concepts.
- **DBMS (Database Management System)**: 
  - `CollegePracticals/`: SQL schemas and database queries.
  - `Theory/`: Notes and theoretical concepts.
- **Foundation of Mathematics**: Theoretical notes and materials.

## 🚀 Getting Started

Navigate to the specific year and semester directory to find the relevant code, schemas, and notes. 

For example, to access the Core Java practicals, you can navigate to:
```bash
cd F.Y./Sem-1/CoreJava/CollegePracticals/
```

To run a Java practical, simply compile and run using standard Java commands:
```bash
javac FileName.java
java FileName
```
